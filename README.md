# Rajan Kumar | Lead SDET | Automation Architect

Portfolio and resume site for Rajan Kumar, published as a static GitHub Pages site.

- Live site: https://dvirusway.github.io/rajan-portfolio/
- GitHub: https://github.com/dvirusway

## Project structure

| File | Purpose |
|---|---|
| `index.html` | Main portfolio page and HTML structure |
| `styles.css` | Site styling and responsive layout |
| `script.js` | Interactive behavior for accordions, tabs, nav, filters, and reveal effects |
| `404.html` | Custom 404 page |
| `Rajan_Kumar_SDET_Resume.pdf` | Downloadable resume |
| `rajan.jpg` / `rajan.webp` | Portrait assets |
| `.nojekyll` | Prevents GitHub Pages from processing the site with Jekyll |
| `gitlab-ci.yml` | Legacy static deployment config kept for reference |
